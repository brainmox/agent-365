Ruler Audit

A leaderboard is a claim. This tool reads the claim's paperwork: who ran it, on whose numbers, when, and against which upstream. Handles the upstream's 0.2.x, 0.3 and 0.4/0.4.1 board editions, the formula files, the vision board, and — since v4 — the methodology file: its published pipeline constants drive a per-benchmark recompute of every area score.

Paste JSON — primary mode, works offline. Blob A: a forked leaderboard copy (e.g. a vendor's own copy of a community index). Blob B (optional): the upstream index JSON it forked from. The fork diff, date gap and provenance census compare the two.

Or fetch by URL — best effort: many leaders serve their JSON without CORS headers, in which case the browser cannot read it and you should curl it and paste. No input is sent anywhere; any fetch goes straight from this page to the URL you name.
