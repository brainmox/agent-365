deltas vs absolutes

Paste a benchmark table from any model announcement. Two modes: prev → new (improvement plus leader re-anchoring) and model card (paste the whole multi-model comparison table; the tool picks the per-benchmark leader itself, so no hand-copied attributions). Or press Fetch live prices to pull a provider's actual price ladder from OpenRouter's public API, where the ranking direction inverts: cheapest wins.
